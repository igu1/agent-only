Admissions assistant — widget demo

The launcher is bottom-right. Open it to see the new-conversation flow.

What to expect

  1. Click the bubble — the popup opens on a warm welcome plus the campus dropdown, not on a text box.
  2. Pick a campus and press Continue — the greeting is rebuilt for that college and the composer unlocks.
  3. Every message now carries that institution_id, so the assistant never asks which college.
  4. The ↻ button in the header starts a new conversation and brings the picker back.

Single-institution school

No dropdown at all. The server returns an empty institutions list, and the panel opens straight onto the greeting.

Page already knows the college

The inquiry page has its own login-time dropdown — pass the choice and the picker never appears:

<script src="webchat-widget.js"
        data-agent="http://127.0.0.1:8001"
        data-channel="1"
        data-institution="3"></script>

Or at runtime, before opening: CronoWebchat.setInstitution(3).
